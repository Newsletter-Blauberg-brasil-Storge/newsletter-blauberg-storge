# Newsletter Blauberg + Storge

Arquivo das edições da newsletter. **Não apague nada daqui:** os e-mails já enviados carregam as imagens destes endereços.

## Estrutura

- `assets/` — imagens fixas, usadas em todas as edições (logos, ícones, divisória, foto de encerramento)
- `AAAA-MM/` — uma pasta por mês de envio
  - `especificadores/`, `obra-e-instalacao/`, `operacao-e-compras/`, `cliente-final/`, `generalista/`
    - `index.html` — o e-mail daquele grupo
    - `images/` — imagens exclusivas da edição (capa)
